# Learning PIC16F877A

Welcome to Learning PIC16F877A. This repository documents my complete learning journey with the PIC16F877A microcontroller, starting from bare-metal programming and gradually progressing toward building custom libraries. The focus is on understanding the microcontroller at a register level rather than relying on high-level abstractions.

In this repository, you will find bare-metal programs, peripheral-level examples, and reusable custom libraries that demonstrate GPIO control, timers, interrupts, and other core features of the PIC16F877A. The code evolves step by step to reflect the learning flow from fundamentals to structured development.

The tools used for this project are MPLAB X IDE for development, the XC8 compiler for compilation, and Proteus for simulation. Source files can be opened directly in MPLAB X IDE, compiled using XC8, and tested through Proteus simulations.

This is an evolving repository, and new examples and libraries will be added continuously as the learning progresses.
